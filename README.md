# Not a DM

เว็บไซต์เกมลับขนาดเล็กที่สร้างด้วย HTML, CSS และ JavaScript ล้วน ๆ โดยไม่ใช้ไลบรารี เฟรมเวิร์ก หรือขั้นตอน build

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งอะไรและไม่ต้องเปิดเซิร์ฟเวอร์

## Deploy ด้วย GitHub Pages

1. Push ไฟล์ทั้งหมดขึ้น repository โดยให้ `index.html` อยู่ที่ root
2. เปิด **Settings → Pages** ใน GitHub
3. เลือก **Deploy from a branch** แล้วเลือก branch ที่ต้องการและโฟลเดอร์ `/ (root)`
4. กด Save และรอ GitHub แสดง URL ของเว็บไซต์

ทุก path ในโปรเจกต์เป็น relative path จึงใช้งานได้ทั้ง repository หลักและ project site ที่มีชื่อ repository ต่อท้าย URL

## การทำงาน

- หน้าแรกจะให้ผู้เล่นกรอกชื่อก่อนเข้าสู่เส้นทางลับ
- ระบบจะตัดช่องว่าง เปลี่ยนชื่อภาษาอังกฤษเป็นตัวพิมพ์เล็ก และรองรับการเว้นวรรคระหว่างคำ
- ชื่อที่อนุญาตจะไปยัง `secret.html` ส่วนชื่ออื่นจะไปยัง `wrong.html`
- เส้นทางลับมีคำถามสนุก ๆ จำนวน 5 ข้อ โดยทุกคำตอบถือว่าถูก
- คำตอบ 4 ข้อแรกจะถูกนำไปสร้างผลวิเคราะห์บุคลิกแบบขำ ๆ ส่วนข้อสุดท้ายเปิดให้ฝากข้อความสั้น ๆ
- เมื่อตอบครบจะไปยังหน้าผลลัพธ์ `ending.html` พร้อมจดหมายแบบพิมพ์ทีละตัว ฉายาสุ่ม และ countdown ก่อนเปิดเพลง
- หากรีเฟรชหน้า `secret.html`, `wrong.html` หรือ `ending.html` ระบบจะพากลับไปกรอกชื่อที่หน้าแรก
- มีดาวลับ 3 ดวงตามเส้นทาง หากเก็บครบจะปลดล็อกข้อความพิเศษ
- พิมพ์ `cat` / `แมว` หรือ `dog` / `หมา` ที่หน้าแรกเพื่อเปิด Easter egg
- มีเอฟเฟกต์ดาวตามเมาส์สำหรับอุปกรณ์ที่รองรับ และจะปิดอัตโนมัติเมื่อผู้ใช้เลือก reduced motion

สถานะการเล่นส่งต่อระหว่างหน้าด้วย query string จึงไม่ต้องใช้ฐานข้อมูลหรือ Web Storage และยังเปิดผ่าน `file://` ได้

## การปรับแต่ง

- แก้รายชื่อที่อนุญาตได้ในตัวแปร `allowedNames` ภายใน `js/main.js`
- แก้คำถามและคำตอบได้ในตัวแปร `quizQuestions` ภายใน `js/main.js`
- เปลี่ยนลิงก์ YouTube ได้ใน `wrong.html` และ `ending.html`
- ใส่รูป เสียง หรือไฟล์เพิ่มเติมไว้ในโฟลเดอร์ `assets/`
